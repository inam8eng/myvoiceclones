CosyVoice voice cloning: free, open for paid work, but not built for Windows

TechBy Inam·November 5, 2026
The short answer

CosyVoice is a free text to speech model from Alibaba's FunAudioLLM team, and it copies a voice from a short recording and its transcript. Unlike Spark-TTS and F5-TTS, both the code and the model files use the Apache 2.0 licence, so you are allowed to use the voice for paid work. The newest version is Fun-CosyVoice3-0.5B, it speaks 9 languages including English, and its install steps are written for Linux, not Windows.

You found CosyVoice because its demos sound natural and it costs nothing. The two questions that matter before you spend an evening on it are simple. Can you sell what you make with it, and will it run on your Windows PC?

Yes, you can use CosyVoice for paid work, because the code and the model files are both Apache 2.0. That makes it different from Spark-TTS and F5-TTS, where the code is open but the model you download is non commercial. The catch is on the other side: the install steps are written for Linux, and Windows takes extra work.

What is CosyVoice?

CosyVoice is a text to speech model, so you type words and it reads them aloud in a voice. It comes from a speech team at Alibaba that publishes as FunAudioLLM, and there have been three versions. The first, CosyVoice-300M, came out in July 2024. CosyVoice2-0.5B followed in December 2024, and Fun-CosyVoice3-0.5B arrived in December 2025.

The 0.5B in the name means about half a billion parameters, which are the numbers a model learns during training. That is small enough to run on a home graphics card. The README on GitHub says the third version covers 9 languages: Chinese, English, Japanese, Korean, German, Spanish, French, Italian and Russian, plus more than 18 Chinese dialects.

Can CosyVoice clone your voice?

Yes. CosyVoice does zero shot cloning, which means it copies a voice from one recording without training on it first. You give it a short audio clip of the speaker and the exact words spoken in that clip, and it reads new text in the same voice.

There is one detail that trips people up with version 3. In the official example, the transcript of your clip does not go in alone. It starts with the line You are a helpful assistant. followed by a marker written as endofprompt inside angle brackets and bars, and only then your words. If you leave that prefix out, the results can come out wrong, so copy the format from example.py in the repository.

The team does not give a fixed clip length. A clean 10 to 20 second recording in a quiet room is a sensible place to start for any instant cloning model. There is also a cross lingual mode that takes only the clip, with no transcript, and reads your text in another language in that voice.

Can you use CosyVoice for commercial work?

This is where CosyVoice stands out. The GitHub repository uses Apache 2.0. The model files on Hugging Face carry the same licence: the Fun-CosyVoice3-0.5B model card, the CosyVoice2-0.5B card and the CosyVoice-300M card all list apache-2.0.

Apache 2.0 lets you use, change and sell work made with the software, as long as you keep the licence notice when you pass the software itself on. Compare that with Spark-TTS and F5-TTS, where the model files are non commercial even though the code is open.

There is one line worth knowing about. The bottom of the README has a disclaimer saying its content is for academic purposes and that some examples come from the internet. That sentence reads as being about the demo samples, not a change to the licence. The licence allows paid work, but you still need the speaker's consent, and that means your own voice or someone who has clearly said yes. I am not a lawyer, so ask one if real money is involved.

Can you run CosyVoice on Windows?

Not officially. The install steps in the README use Conda with Python 3.10, and the commands they show for system packages are for Ubuntu and CentOS, which are Linux. There is no Windows guide in the README.

The requirements file shows what changes on Windows. DeepSpeed, the GPU build of ONNX Runtime and TensorRT are marked Linux only, and Windows gets the plain ONNX Runtime instead. The optional text cleanup package, ttsfrd, ships as a Linux only file too. The README says that package is not necessary and that CosyVoice falls back to a simpler one called wetext, so Windows can still read numbers and symbols.

In plain steps, you clone the repository with its submodules, create a Python 3.10 Conda environment, install the requirements, then download the model files from Hugging Face. The README pins PyTorch 2.3.1 built for CUDA 12.1, so an NVIDIA card is the comfortable route. Expect to fix one or two install errors on Windows, and test one short sentence before you plan a big project.

How does CosyVoice compare with F5-TTS and Spark-TTS?

The CosyVoice team publishes a comparison table in its README. Speaker similarity there is a score for how close the cloned voice sounds to the original, measured by a separate model. These are the team's own numbers, not an independent test, so treat them as a guide.

CosyVoice or GPT-SoVITS for your own voice?

CosyVoice is a strong pick if you work on Linux, need several languages, or want an open licence with no small print on the model. It also streams, so it can start speaking quickly while it is still working on the rest of the text.

If you are on Windows and only need English in your own voice, GPT-SoVITS is easier to start with. It has an MIT licence, clones from a 5 second clip, and can fine tune on about 1 minute of audio, which keeps your accent steadier over a long script. It also has a ready made Windows package, and I cover the setup in my guide to installing GPT-SoVITS on Windows.

FAQ

Is CosyVoice free for commercial use?

Yes, by its licence. The code on GitHub and the model files on Hugging Face are all Apache 2.0, which allows paid work, unlike Spark-TTS and F5-TTS whose model files are non commercial.

What languages does CosyVoice support?

Fun-CosyVoice3 covers 9 languages: Chinese, English, Japanese, Korean, German, Spanish, French, Italian and Russian. It also handles more than 18 Chinese dialects and can clone a voice across languages.

Does CosyVoice work on Windows?

There are no official Windows steps, because the README is written for Linux. The requirements file swaps a few Linux only packages for plain ones on Windows, so it can be installed, but expect some fixing along the way.

Does CosyVoice need a transcript of my clip?

The standard cloning mode needs the clip and the exact words spoken in it. For version 3, the official example puts a short fixed prompt in front of those words, so copy the format from example.py.
