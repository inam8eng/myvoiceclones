Qwen3-TTS voice cloning: a 3 second clone, free for paid work, but test the speed first

The short answer

Qwen3-TTS is a free text to speech model from Alibaba's Qwen team released on 22 January 2026, and it copies a voice from about 3 seconds of audio plus the words spoken in it. The code and the model files use the Apache 2.0 licence, so paid work is allowed. Only the two Base models clone a voice, and owners of home graphics cards report slow generation, so test the speed before you plan a long project on it.

You probably heard that Qwen3-TTS can copy a voice from 3 seconds of audio, and that it is free. Both are true. What you want to know before you install it is whether you can sell what you make, and whether it will be fast enough on your own computer.

Yes, you can use Qwen3-TTS for paid work, because the code and the model files are all Apache 2.0. The speed is the real question. The team quotes 97 milliseconds for the first sound, but people with strong home graphics cards report waiting several seconds for each second of speech, so test it on your own card before you plan a long project on it.

What is Qwen3-TTS?

Qwen3-TTS is a text to speech model, so you type words and it reads them aloud. It comes from the Qwen team at Alibaba, and the first release came out on 22 January 2026. It speaks 10 languages: Chinese, English, Japanese, Korean, German, French, Russian, Portuguese, Spanish and Italian. You can read all of this in the README on GitHub.

The 1.7B and 0.6B in the model names mean how many parameters each one has, about 1.7 billion or about 0.6 billion. Parameters are the numbers a model learns during training, and more of them usually means a bigger download and more work for your graphics card. When I added up the files on Hugging Face, the 1.7B-Base came to about 4.5 GB and the 0.6B-Base to about 2.5 GB.

Which Qwen3-TTS model clones a voice?

This trips people up, because the model names do not say it. The team published three kinds, and only the Base models clone your voice.

ModelWhat it doesClones your voice?
1.7B-Base and 0.6B-BaseCopies a voice from your audio clipYes
1.7B-CustomVoice and 0.6B-CustomVoice9 ready made voices, and you pick oneNo
1.7B-VoiceDesignInvents a new voice from a written descriptionNo

If you download CustomVoice and then look for the place to add your recording, you will not find it. Start with Qwen3-TTS-12Hz-1.7B-Base if your card can hold it, and the 0.6B-Base if it cannot.

How does Qwen3-TTS clone a voice?

It does what is called zero shot cloning, which means it copies a voice straight from one recording with no training first. You give it the clip and a transcript, which is the exact words spoken in that clip, and it reads your new text in the same voice.

There is a shortcut that skips the transcript, a setting called x_vector_only_mode. It uses only a summary of the speaker and the README warns that quality may drop, so write the transcript out if you can.

You can run it from Python or from a small web page it starts on your computer, using the command qwen-tts-demo. If you open that page from another computer, the README says to use HTTPS, so that the browser does not block the microphone.

Why does Qwen3-TTS speed up on long text?

This is the most useful thing I found while reading the project's bug reports. People cloning a voice for long scripts noticed that the voice starts at a normal pace and then rushes toward the end. The report on GitHub was opened in February 2026 by someone generating text over 100 characters.

In August 2026 a team narrating audiobooks with the 1.7B-Base model posted measurements in that same thread, and they point at something you can control. In streaming mode, a 12.9 second reference clip made the voice speed up by 16.7% within one generation of about 25 seconds. A 4 second slice of the same clip changed it by only 2.3%, and that was slower rather than faster, and turning streaming off on the long clip showed no drift at all. Streaming is on by default for voice cloning in the package, and the setting that turns it off is non_streaming_mode=True.

These are one team's numbers, not the Qwen team's, but they are easy to act on. Use a short clip of about 4 seconds, not a long one, and make your script one or two sentences at a time. This is the opposite of what most voice cloning tools want, where more audio is usually better.

Is Qwen3-TTS fast on a home PC?

It depends on your card and your setup, and the reports are not flattering. The 97 millisecond figure in the README describes how soon the first sound can come out in the team's streaming design. It does not tell you how long a full sentence takes on your computer.

Here is what users wrote in one long thread about speed. Someone on Windows 11 with an RTX 5090 waited over 50 seconds for one short sentence, with the graphics card sitting at only 4 to 5% use. Someone with a 4070 Ti Super got 5 seconds of waiting for each 1 second of audio. Another person reported about 6 times the speed after changing how the model is compiled in their own fork, so it can be improved, but that means editing code.

There is also a memory report. Video memory keeps climbing when you generate one text after another, and a user with a 12 GB RTX 3060 hit it after 2 or 3 generations. A workaround posted in July 2026 only slowed it down, so for a long script, plan on restarting the model now and then.

None of this makes Qwen3-TTS bad. In the team's own test on English, the 1.7B-Base had the lowest word error rate of the models they listed, at 1.24, which means it rarely says the wrong word. It is a strong model that was not tuned for a normal desktop.

Can you use Qwen3-TTS for commercial work?

Yes. The GitHub repository uses Apache 2.0, and every Qwen3-TTS model card I checked on Hugging Face lists apache-2.0 too. Apache 2.0 lets you use and sell work made with the software, as long as you keep the licence notice if you pass the software itself on.

That puts it with CosyVoice and ahead of F5-TTS, where the official model is non commercial. The licence only covers the software, and it does not give you the right to copy a person's voice, so clone your own or get a clear yes from the owner.

How do you install Qwen3-TTS on Windows?

There is no Windows package, so this is a Python install. The README suggests a clean Conda environment with Python 3.12, and then one command:

  1. Run conda create -n qwen3-tts python=3.12 -y and then conda activate qwen3-tts.
  2. Run pip install -U qwen-tts. A fresh environment matters because the package pins an exact version of Transformers, 4.57.3, and that can clash with your other AI tools.
  3. Start the page with qwen-tts-demo Qwen/Qwen3-TTS-12Hz-1.7B-Base --ip 0.0.0.0 --port 8000. The model downloads on first use.

The README also recommends FlashAttention 2 to lower video memory use. It is a recommendation, so if it refuses to build on your computer, try removing that setting from the example code before you give up.

Can you fine tune Qwen3-TTS on your own voice?

Yes, and fine tuning means training the model further on many clips of one speaker, so it holds that voice more steadily. The fine tuning guide supports one speaker at a time, and you prepare a list of audio files with their transcripts.

I would treat this as a project, not a button. In the bug reports people describe speech getting faster with every round of training, and others got pure noise until they lowered the learning rate, which is how big a step the model takes each time it learns. The README's example now uses the lower value of 2e-6.

When should you pick something else?

Pick Qwen3-TTS if you have a strong NVIDIA card, you are comfortable with Python, and you need paid use or one of its 10 languages. If you are on Windows and only need English in your own voice, GPT-SoVITS is the easier start. It has an MIT licence and a ready made Windows package, and my guide to installing GPT-SoVITS on Windows walks through it.

FAQ

Is Qwen3-TTS free for commercial use?

Yes. Apache 2.0 covers both the GitHub code and the Hugging Face models, so paid work is allowed, though you still need the right to use the voice you clone.

How much audio does Qwen3-TTS need to clone a voice?

The team says about 3 seconds for its Base models, along with the words spoken in the clip. One audiobook team measured a 4 second clip holding a steadier pace than a 12.9 second clip, so a short clean recording is a good place to start.

Why is Qwen3-TTS so slow on my PC?

Many users report the same thing, even on strong cards, and one person saw only 4 to 5% graphics card use on an RTX 5090. Check that the model really loaded on your graphics card, try the smaller 0.6B-Base model, and keep each generation short.

Does Qwen3-TTS work on Windows?

People do run it on Windows 11, but there is no Windows package, so you install it through Python. Use a fresh Conda environment, because the package pins an exact version of Transformers.
