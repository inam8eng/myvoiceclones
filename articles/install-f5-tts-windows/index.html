How to install F5-TTS on Windows: PyTorch first, then FFmpeg, and where the 1.35 GB model lands

GuidesBy Inam·November 27, 2026
The short answer

To get F5-TTS running on Windows, set up a Python 3.11 environment first, then install FFmpeg, then install the NVIDIA build of PyTorch, and run pip install f5-tts last. After that, launch it with f5-tts_infer-gradio and open 127.0.0.1:7860 in your browser. The first time you generate audio, it downloads a 1.35 GB model into a hidden .cache folder on your C drive, and if you leave the reference text box empty, it pulls down a 1.62 GB speech recognizer too.

If you have heard an F5-TTS demo where a ten second clip of someone speaking turns into a full paragraph in that same voice, you probably want to run it on your own Windows PC. Looking at the GitHub page, it seems like a single command, pip install f5-tts, should be enough. On Windows, running only that command is where most people hit trouble, because the install succeeds, and then the audio either takes forever to generate or comes out completely silent.

Follow this exact order: install FFmpeg first, then the NVIDIA build of PyTorch, and run pip install f5-tts last. Also type the words from your audio clip into the reference text box. Getting the order right is what makes F5-TTS run on your graphics card, and typing those words yourself skips an extra 1.62 GB download. I have put the full setup steps below, followed by a few details I saw in the code that most guides leave out, including where the model files actually land on your disk.

What do you need before you install F5-TTS?

Before you start, your PC needs three things, and all of them are listed in the F5-TTS README on GitHub. First, you need Python 3.10 or newer inside its own separate environment, which is just an isolated folder of Python packages so installing this tool will not mess up anything else on your machine. The README uses conda to manage that, and its example uses Python 3.11. Second, you need FFmpeg, a free tool that reads and converts audio files, and third, you need PyTorch, which is the library that actually runs the voice model.

On the hardware side, an NVIDIA graphics card is the standard setup for Windows. The README mentions Intel cards and Apple chips as well, while AMD cards are listed for Linux only. I looked through the README for a minimum graphics memory requirement and did not find one, so I will not make up a number here.

People often overlook disk space until something runs out of room. By my own estimate, the Python packages alone take a few GB, the main model adds 1.35 GB, and there is an optional piece that takes another 1.62 GB, though I will show you how to avoid downloading that part further down.

How do you install F5-TTS on Windows, step by step?

I am sticking with conda for these steps because the README uses it and it lets you install FFmpeg in a single command. If conda is not on your PC yet, install Miniconda first, then open Anaconda Prompt and run each command below in order.

  1. Create and switch into the environment: conda create -n f5-tts python=3.11 followed by conda activate f5-tts.
  2. Install FFmpeg with conda install ffmpeg.
  3. Install the NVIDIA version of PyTorch: pip install torch==2.8.0+cu128 torchaudio==2.8.0+cu128 --extra-index-url https://download.pytorch.org/whl/cu128. This is the exact example command from the README.
  4. Check that PyTorch can see your graphics card: python -c "import torch; print(torch.cuda.is_available())". You need to see True printed back.
  5. Install F5-TTS itself: pip install f5-tts.
  6. Start the web interface with f5-tts_infer-gradio, then open http://127.0.0.1:7860 in your browser.

After this first setup, starting F5-TTS on another day takes just two commands. Open Anaconda Prompt, run conda activate f5-tts, and then run f5-tts_infer-gradio.

If you prefer not to install conda, the README notes that a regular Python virtual environment works as well. You will need to install FFmpeg on your own in that case, and one easy way is to run winget install ffmpeg in a standard terminal. Once it finishes, close that terminal, open a fresh one, and run ffmpeg -version to confirm Windows recognizes it before moving ahead.

Why does PyTorch have to go in before pip install f5-tts?

Skipping the PyTorch step is the mistake that usually wastes an entire evening. The F5-TTS package only requires PyTorch 2.0.0 or newer without specifying which build to use. Because of that, if PyTorch is not already installed, pip fetches it automatically, and on Windows the default package index gives you the version that only runs on your processor.

The tricky part is that nothing actually throws an error. The installation completes, the browser page loads, and you still get audio out of it. Everything just runs very slowly because a model built for a graphics card is being forced onto your processor, and nothing on screen warns you about it.

That is the whole reason I included step 4. CUDA is NVIDIA's software layer for running AI workloads on its graphics cards, and that short command asks PyTorch whether it can talk to CUDA. If it prints False, stop right there and fix your PyTorch install before going any further. The command in step 3 is built for CUDA 12.8, the README also includes an older command for CUDA 12.4, and you can grab the matching command for other setups from the PyTorch install page.

What does F5-TTS download the first time, and where does it put it?

Running step 5 does not download the voice model yet. The actual download starts the first time you click the generate button, which is why your very first run looks stuck for a bit. Behind the scenes, it pulls a 1.35 GB file named model_1250000.safetensors from the F5-TTS files on Hugging Face. At the same time, it downloads a 54 MB vocoder called Vocos, which is the smaller component that turns the model's raw output into audio you can listen to.

Here is something I only caught by reading through the code. Neither of those files gets saved inside the folder where you installed F5-TTS. Instead, the model lands in C:\Users\YourName\.cache\cached_path and the vocoder lands in C:\Users\YourName\.cache\huggingface\hub, so both sit on your C drive no matter which drive you installed the environment on.

If your C drive is low on space, that is where the download will fail, even if you have plenty of free room on your D drive. Looking at how the loader works, it checks an environment variable called CACHED_PATH_CACHE_ROOT, and Hugging Face uses its own documented variable called HF_HOME. If you run set CACHED_PATH_CACHE_ROOT=D:\f5-cache and set HF_HOME=D:\hf-cache in the same terminal window before launching the page, both downloads should go to your D drive instead. I found that by reading the code, so to be clear, I have not tested moving the cache on my own PC.

Why should you type the reference text yourself?

On the web page, you will see a box labeled reference text where you are supposed to enter the exact words spoken in your sample clip. A small note underneath mentions that you can leave the box empty and let the tool transcribe the clip for you. That works, but it comes with a catch.

To figure out the words on its own, the tool loads a second model called Whisper large v3 turbo, which is OpenAI's speech recognition model. The main file for it is 1.62 GB, making it larger than F5-TTS itself, and the README points out that it uses extra GPU memory too. It only downloads and loads if you leave that reference text box blank.

Type the words of your clip into that box yourself, and the 1.62 GB download will never trigger. You already know what was said in those ten seconds, and what you type will be more accurate than an automated transcript anyway. The Voice Chat tab works in a similar way, since it pulls down a chat model called Qwen2.5-3B-Instruct, but only if you click its Load Chat Model button.

What happens to a clip longer than 12 seconds?

If you upload a long clip, F5-TTS trims it automatically without asking you. The README mentions that long reference audio gets shortened to around 12 seconds. From the code, it first searches for a pause so the trimmed audio stays under 12 seconds, and if there is no clear pause, it cuts right at 12 seconds flat, which can slice straight through a word.

Slicing a word in half hurts the voice quality because the audio ends with a partial word that does not match the text you typed. It is better to trim your audio clip yourself before uploading it. Keep the length under 12 seconds, finish on a complete sentence, and leave about one second of silence at the end as the README suggests.

There is another limit that tends to confuse people at first. Each single generation tops out at 30 seconds, and your reference clip counts toward that 30 seconds. If you paste in a longer script, the interface breaks your text into smaller pieces and stitches the audio back together automatically, so longer passages still work, they are just generated in chunks. If you want help getting a clean recording, I covered that side in how to record a voice sample that clones well.

Why is the output silent, or the page not opening?

If your generated audio file plays back as complete silence, check your FFmpeg setup first. The README calls this out directly in a single line: if the output is blank or pure silence, check your FFmpeg installation. That is why step 2 is placed near the top, and why I recommend running ffmpeg -version if you installed it without conda.

If the browser page fails to load, double-check the address you typed. When you launch F5-TTS with the plain command, it listens only on your local PC, so http://127.0.0.1:7860 works on that machine while other devices on your Wi-Fi cannot reach it. That is a safer default than what some other voice tools use, like the one that opens itself to your whole local network which I noted in how to install IndexTTS2 on Windows.

Watch out for one command example in the README, though. It lists f5-tts_infer-gradio --port 7860 --host 0.0.0.0, and setting the host to that value exposes the page to every device on your network. There is also a --share flag that creates a public link, which stays off unless you type it in yourself. If you are just working with your own voice on your own PC, launch it with no extra flags at all.

Which version are you getting today?

Right now, running pip install f5-tts installs version 1.2.0. That release was published on PyPI and GitHub on 26 November 2026, just one day before I wrote this. Its release notes mention five fixes, including one that restores device detection on PyTorch 2.6, which matters if you already have that version of PyTorch installed for another project.

Using a release that is only one day old has two sides to it. You get the latest fixes right away, but you could also run into a fresh bug before others have reported it. That said, the repository is active, showing 15,669 stars and 71 open issues and pull requests on GitHub tonight, so if something goes wrong, there is a fair chance someone has already posted about it.

When is this install not worth your evening?

F5-TTS is a good fit if you do not mind using a terminal and you want to test cloning a voice from a single short clip without any training step. It supports both English and Chinese, and it lets you switch between multiple voices inside one script. By comparison, my own app only supports English.

Where F5-TTS falls short is paid or commercial work. While the source code uses the MIT licence, the official model is released under CC BY-NC because of its training data, which means commercial use is not allowed. I broke down those licence terms in my F5-TTS voice cloning article, so check that before using the output in any video that makes money.

Having a graphics card speeds it up, though a regular processor still works.

FAQ

Does F5-TTS work on Windows?

Yes, it runs on Windows. You create a Python environment, install FFmpeg and the NVIDIA build of PyTorch first, and then run pip install f5-tts. Running f5-tts_infer-gradio starts the web interface locally on your PC at 127.0.0.1:7860.

How big is the F5-TTS download?

The main F5TTS_v1_Base model is 1.35 GB and the Vocos vocoder is 54 MB, and both are downloaded when you generate audio for the first time. Leaving the reference text box blank triggers an additional 1.62 GB download for the Whisper model, and the Python packages take extra space on top of that.

Where does F5-TTS save its model on Windows?

F5-TTS saves the model inside .cache\cached_path in your user folder on the C drive, while the vocoder goes into .cache\huggingface\hub in that same user folder. Neither file is stored in the folder where you ran the installation.

Why is F5-TTS so slow on my PC?

Most of the time, it is slow because pip pulled the processor only build of PyTorch. Run python -c "import torch; print(torch.cuda.is_available())" inside your environment, and if you see False, install the NVIDIA build of PyTorch and try again.
