VibeVoice voice cloning: what Microsoft took down, and what you can still use in 2026

TechBy Inam·October 30, 2026
The short answer

VibeVoice is a family of free speech models from Microsoft under the MIT licence. Its long form text to speech model, which could copy voices for up to 4 speakers and 90 minutes, was released on 25 August 2025, and Microsoft removed that code from GitHub on 5 September 2025 after finding it used in ways it did not intend. The newer VibeVoice-Realtime-0.5B cannot clone a voice, because Microsoft removed the part that would let you make your own. Microsoft labels all of it research only.

You might have seen VibeVoice in a YouTube video where two or three AI voices hold a whole podcast together, and it sounds close to real people talking. Then you go to the GitHub page to try it and the code is not there. That confuses a lot of people, and most of the guides you find were written before Microsoft changed things.

Microsoft took the voice cloning version of VibeVoice off its official GitHub on 5 September 2025, and the model it offers now cannot copy your voice at all. So if you want to clone your own voice for videos, the official VibeVoice is not the tool for that today. I will explain what happened, what is still there, and what the research only label means for you.

What is VibeVoice?

VibeVoice is a group of open speech models from Microsoft, and the VibeVoice GitHub page calls it a family of open source voice AI models. Some of them turn text into speech, which is called text to speech or TTS. Others do the opposite and turn speech into text, which is called speech recognition or ASR.

The one people got excited about was VibeVoice-TTS, released on 25 August 2025. It could write long audio, up to 90 minutes, with up to 4 different speakers in it. You gave it a short sample of each voice and it copied them, so you could make a full conversation from a script.

Why did Microsoft remove VibeVoice?

The GitHub page has a note dated 5 September 2025, only eleven days after the release. It says the team found the tool being used in ways that did not match what it was made for. Because responsible AI is one of Microsoft's principles, they removed the VibeVoice-TTS code from the repository.

The note does not say what the misuse was. But a model that copies anyone's voice from a short clip, for 90 minutes, with several people talking, is exactly what someone needs to fake a phone call or a recording of a real person. So the reason is not hard to guess, even if Microsoft did not spell it out.

Can VibeVoice-Realtime clone a voice?

No, and this is the part most guides get wrong. Microsoft released VibeVoice-Realtime-0.5B on 3 December 2025, and it is still on GitHub and Hugging Face. It starts speaking in about 300 milliseconds, so it is fast enough for live use, but it only speaks with one voice at a time and it only uses voices Microsoft gives you.

The Realtime model page on Hugging Face says the team removed the acoustic tokenizer to stop users creating their own embeddings. In plain words, the tokenizer is the part that listens to a clip and turns a voice into numbers the model can copy. Without it, you cannot feed in your own recording. On 16 December 2025 Microsoft added some extra speakers in other languages, but those are still their voices, not yours.

Is VibeVoice still available to download?

Partly, and it depends on which piece you mean. The official repository today holds the speech recognition models and the Realtime model, and its own table marks the old TTS weights as disabled. A model page for VibeVoice-1.5B is still up on Hugging Face, but the code that runs it is no longer on Microsoft's GitHub.

A group of users kept a copy. The vibevoice-community fork describes itself as a community backup made after Microsoft removed the original repository and models. Its README says the 1.5B and 7B models support up to 4 speakers with voice cloning from audio samples. Microsoft does not maintain that copy, so you get no fixes from them and you are trusting strangers with code you run on your PC.

Can you use VibeVoice for YouTube or client work?

The code and models carry the MIT licence, which on its own allows commercial use. But Microsoft's model pages say VibeVoice is for research and development only, and they do not recommend it for commercial or real world use without further testing. That is advice, not a licence term, but it tells you the maker does not stand behind it for paid work.

There is also a practical problem for videos. Microsoft's model pages say every file it makes carries an audible disclaimer, something like "This segment was generated by AI", plus a hidden watermark. So even where the official model runs, its output tells the listener it is AI. The pages also list voice impersonation without explicit, recorded consent as out of scope, so cloning someone else's voice is against the rules either way.

VibeVoice or GPT-SoVITS: which one should you use?

They are built for different jobs. VibeVoice was made for long, many speaker audio like podcasts, and Realtime is made for fast replies in an app with a stock voice. If you want a quick English voice for a prototype and you do not need it to be yours, Realtime is a fair choice, and its speech recognition models are genuinely useful on their own.

If you want your own voice, GPT-SoVITS is the open engine I chose for VoiceClone. Its code is under MIT, it is still maintained, and it can be trained on a few minutes of your talking, so it gets your accent and rhythm closer than a copy from one clip. On its own it is a technical install, and I explained it in GPT-SoVITS in plain words. For another free model that does still clone from one clip, see my page on IndexTTS2 and its licence.

FAQ

Is VibeVoice free?

Yes, the models are free and the code is under the MIT licence. But Microsoft says they are meant for research and development, and it does not recommend them for commercial use without more testing.

Why was VibeVoice taken down?

On 5 September 2025 Microsoft said it found the text to speech tool being used in ways that did not match its intent, so it removed that code from GitHub. The Realtime model and the speech recognition models are still there.

Can VibeVoice clone my voice?

The official Realtime model cannot, because Microsoft removed the part that turns your recording into a voice it can copy. Only an unofficial community copy of the older model still offers voice cloning, and Microsoft does not support it.

Does VibeVoice add a watermark?

Microsoft's model pages say every file carries an audible disclaimer saying it was generated by AI, plus a watermark you cannot hear. That makes the official output a poor fit for a normal voiceover.
